# 📊 Analyse Statistique Pro

Application web d'analyse statistique interactive construite avec Streamlit.

## Fonctionnalités
- 📥 Import de fichiers CSV/Excel ou données d'exemple
- 🧹 Nettoyage (doublons, valeurs manquantes, renommage)
- 📊 Statistiques descriptives
- 🧪 Tests d'hypothèses (t-test, ANOVA, corrélation, Chi²)
- 📈 Graphiques interactifs (Plotly)
- 📄 Export des résultats (CSV, TXT, Excel)

## Lancer en local
```bash
pip install -r requirements.txt
streamlit run app.py
